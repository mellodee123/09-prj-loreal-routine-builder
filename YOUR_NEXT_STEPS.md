## 📝 The 4 Steps (In a Nutshell)

### Step 1: Get API Key (5 minutes)
```
Go to: https://www.perplexity.ai/api
Sign up (free)
Create API key
Copy it
```

### Step 2: Update Worker Code (5 minutes)
```
Cloudflare Dashboard
  → Workers & Pages
  → Your Worker
  → Editor tab
  → Copy code from EXACT_WORKER_CODE.md
  → Paste all of it
  → Click Deploy
```

### Step 3: Add Environment Variable (3 minutes)
```
Cloudflare Worker
  → Settings tab
  → Environment Variables
  → Add variable
  → Name: PERPLEXITY_API_KEY
  → Value: (your API key)
  → Save and deploy
```

### Step 4: Test (2 minutes)
```
Open your app
Select products
Click "Generate Routine"
Check for:
  ✓ Current information
  ✓ Clickable links
  ✓ Customer reviews
  ✓ Citations
```
